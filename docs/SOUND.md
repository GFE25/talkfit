# サウンドロゴの設計

記録音は「好み」ではなく、次のルールで決めた。変更するときもこの表に照らす。

| 狙い | 根拠 | 音への反映 |
|---|---|---|
| 「できた」を行動に結びつける | 行動の直後に同じ報酬が返ると習慣化（条件づけ） | 毎セット同じ音。声の直後、全長0.35秒、立ち上がり6ms |
| 前向きに聞こえる | 上行＝成功・前進、下行＝失敗・悲しみ | 成功は上行、失敗（低い「ブブッ」）と一聞きで区別 |
| 心地よさ | 単純な周波数比（3:2・5:4・2:1）は協和、うなり（粗さ）が少ない | 純正律。倍音は整数倍のみ（金属的な非整数倍音は使わない） |
| 耳に刺さらない | 2.5〜4kHzは聴覚が最も敏感 | 4.2kHzでローパス。2.5〜5kHz成分は1%未満 |
| 覚えられる | 単純接触効果、短く単純な音形は定着が早い | 毎セット音（D→A）が終了音の冒頭に入り、終了音で回収される |
| 終わりの満足感 | ピーク・エンドの法則、主音への着地＝解決 | 終了音は D→A→高いD（主音）、長3度を薄く重ねる。約1秒 |
| 音楽・驚きへの配慮 | 突然の大音量は驚愕反応。音楽の主成分は200Hz〜2kHz | 毎セット音は約-10dBFS、終了音はやや大きめ |

基準音は D5（587.33Hz）。変えるなら `index.html` の `SND_BASE` と Swift の `d5` を揃える。
これは一般的な傾向に基づく設計で、最適の証明ではない。ジムで飽きないか・音楽の上で聞こえるかは実機で確かめる。
