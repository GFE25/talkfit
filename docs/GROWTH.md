# TalkFit 集客の素材集

方針：**「ポケットに入れたまま記録される」瞬間を見せる**。説明より、動いている映像が一番強い。
会社名・勤務先には触れない（副業の線引きのため）。発信は個人として。

---

## 1. 撮るべき動画（TikTok / Instagram リール / YouTube ショート 共通）

縦型・15〜30秒・最初の1.5秒で結論を見せる。字幕は必須（無音で見られる）。

### ① ポケット検証（これが本命）
- 0-2s：スマホをポケットに入れる手元。字幕「スマホ、ポケットに入れたまま」
- 2-8s：ベンチを1セット。終わって座りながら小声で「ベンチ80キロ10回」
- 8-12s：ポケットから出すと記録されている画面のアップ。字幕「勝手に記録されてる」
- 12-15s：今日の総重量の数字。字幕「筋トレ記録、もう入力しない」
- キャプション：手入力やめました。声で記録するアプリ作った #筋トレ #筋トレ記録 #ジム

### ② 音楽そのまま
- AirPods で音楽が流れている画面 → 「同じで8回」とつぶやく → 記録が増える
- 字幕「音楽は止めない。つぶやくだけ」

### ③ 1ヶ月の変化
- サマリーの「今月」を表示し、前月比 +◯% と部位マップを見せる
- 字幕「声で記録してたら、1ヶ月でこれだけ伸びてた」（実データが溜まってから）

### ④ 開発者の独白
- 「筋トレが続かない理由は根性じゃなくて、成長が見えないからだと思って、これを作った」
- 顔出し不要。画面録画＋ナレーションで可

### ⑤ よくある失敗あるある
- 「インターバル中にスマホ触って、気づいたら5分経ってる人」→ 声で記録で解決

**頻度**：最初の4週間は週3本。①は角度・種目を変えて何度出してもいい。

## 2. X（旧Twitter）投稿

プロフィール：「声だけで筋トレを記録するアプリ TalkFit を個人開発中。週◯回ジム。」
固定ポスト：①の動画＋LPリンク。

ローンチ前（毎日1本、開発の過程を見せる）
1. 筋トレの記録、インターバル中にスマホいじってたら毎回5分溶けてたので、声だけで記録できるアプリを作ってる
2. 「ベンチ80キロ10回」って言うだけで記録されるの、思ってた100倍快適だった
3. 音楽聴きながら声を拾うのが一番難しかった。声と音楽を見分けるのをやめて、全部書き起こして数字が取れた時だけ記録する方式にしたら一気に安定した
4. 筋トレが続かないのは根性の問題じゃなくて、伸びてるのが見えないからだと思う。前回比が見えるだけで、次のジムが楽しみになる
5. 「同じで8回」で前の種目と重量を引き継ぐようにした。2セット目以降はほぼ回数しか言わない
6. 自分で20回以上ジムで試して、やっと「スマホを触らずに1回のトレーニングが終わる」ようになった
7. 来週から無料で公開します。iPhoneのSafariで開くだけで使える（インストール不要）

ローンチ当日
8. TalkFit 公開しました。セット後につぶやくだけで筋トレが記録されるアプリです。14日間全部無料、カード登録なし。[LP URL]
9. （①の動画）手入力、もうしない。
10. 使ってくれた人の感想を全部読んでます。「この言い方が通じなかった」を送ってくれたら即直します

ローンチ後（週3〜4本）
11. 今週追加した機能：◯◯（ユーザーの声から）
12. 今月の自分の総重量 ◯◯kg、先月比+◯%（シェア画像）
13. 「腕立て30回」「プランク1分」も声で記録できます
14. ジムで小声でつぶやくのが恥ずかしい問題 → AirPods のマイクで、ほぼ聞こえない声量でOK
15. 有料会員◯人になりました。ありがとうございます（数字の公開は応援されやすい）

**やること**：筋トレ系アカウントの投稿に、宣伝ではなく本気のリプを毎日5件。
自分の投稿のリプには全部返す。

4. 一番苦労したこと：ジムの騒音と音楽の中で声を拾う（試行錯誤の具体）

6. 14日間無料で使えます、リンク
7. 今後：食事・読書など「つぶやくだけで人生が積み上がる」ところまで広げたい

## 6. 計測の見方（毎週日曜に管理画面で確認）

| 指標 | 意味 | 目安 |
|---|---|---|
| lp_view → lp_cta | LP の説得力 | 15% 以上 |
| 新規 → voice_start | 初回体験の到達率 | 60% 以上 |
| voice_start → set_voice | 声で1件記録できた率 | 70% 以上（低いなら認識精度の問題） |
| D7継続率 | 1週間後も使っているか | 30% 以上 |
| paywall_view → checkout_click | 価格・訴求の妥当性 | 10% 以上 |
| checkout_click → checkout_success | 決済の離脱 | 60% 以上 |

一番低い所だけを、その週に直す。
